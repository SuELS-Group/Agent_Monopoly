# 🎩 Monopoly MAS: LLM-Driven Simulation Environment

**Internal Research Project - Carl von Ossietzky University Oldenburg (SuELS Project)**

This repository contains a highly realistic, zero-sum Multi-Agent System (MAS) simulation environment designed to observe, analyze, and benchmark emergent behaviors of Large Language Models (LLMs) playing by the strict official Monopoly ruleset.

## 🔬 Project Architecture & Workflow

The system is strictly decoupled into three main layers:

- **Physics Engine (Backend):** Python/FastAPI deterministic engine enforcing rules (mortgages, auctions, even-build rule).
- **Cognitive Layer (LLMs):** Agents powered by local LLMs (Meta's llama3, Mistral AI's mistral) via the Ollama REST API.
- **Observation Dashboard (Frontend):** Next.js/React interface for real-time monitoring, live "Chain of Thought" (CoT) tracking, and JSON data extraction.

## 🔌 Workstation Connection Setup (Private Access)

Because inference requires significant GPU resources, the LLMs run on the university workstation (suels-workstation2), while the engine and dashboard can be run locally for rapid development.

### 1\. Establish the SSH Tunnel (API Forwarding)

Bind your local machine to the workstation's Ollama service port. Open a terminal and run:

ssh -L 11434:localhost:11434 mathis@suels-workstation2

_(Keep this terminal open and minimized in the background)._

### 2\. Start the Physics Engine (Local)

Ensure you have requests, fastapi, and uvicorn installed.

cd backend  
uvicorn server:app --reload

### 3\. Start the Observation Dashboard (Local)

Replace the default Next.js configurations if necessary.

cd frontend  
npm install  
npm run dev

Navigate to <http://localhost:3000> to start the simulation and monitor the agents.

## 📸 Cognitive Analytics & Memory Systems

### Real-Time Strategic Processing

_Live extraction of LLM Chain of Thought. The Python backend utilizes a strict custom parser to strip Markdown wrappers (e.g., \`\`\`json) generated by models like Llama-3, ensuring uninterrupted JSON evaluation._

### Continuous Learning (Post-Mortem Memory)

_Upon bankruptcy, the engine triggers a RAG-based Post-Mortem evaluation. The eliminated agent analyzes the 15 preceding event logs, synthesizes a strategic heuristic, and persists this rule into a local memory_\[agent*name\].json file to alter its behavior in subsequent iterations.*
